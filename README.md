🚀 **Introducing MORROW — AI-Powered 3D Goal Planning**

I'm excited to share MORROW, a web application I developed to make goal planning more visual, interactive, and actionable.

✨ **What MORROW offers:**
- AI-generated goal pathways and actionable tasks
- An immersive, space-inspired 3D interface
- Task tracking and progress persistence
- AI integration using the Groq API
- Cloud deployment with GitHub Pages and Render

🛠️ **Tech Stack:** HTML, CSS, JavaScript, Three.js, Python, Flask, Groq API, GitHub, and Render.

Building MORROW has helped me explore AI integration, frontend and backend development, 3D visualization, and deployment workflows.

🌐 **Explore the project:** https://madhu2694.github.io/morrow/
